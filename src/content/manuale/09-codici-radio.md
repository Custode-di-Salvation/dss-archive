## POLICY 1000: COMUNICAZIONI RADIO E 10-CODES

### 1000.1 STANDARD DELLE COMUNICAZIONI
Per garantire comunicazioni rapide, univoche e sicure via radio tra le unità sul campo e il dispatch centrale, il Dipartimento adotta il set standard dei *10-Codes* nordamericani. È vietato l'uso di linguaggio in chiaro o non criptato per informazioni sensibili o per i dettagli medici delle vittime.

I codici dal **10-1 al 10-99** seguono il set standard mondano per le operazioni di pattuglia (FOU) e criminali (CIU).

| Codice | Significato |
| :--- | :--- |
| **10‑1** | Ricezione scarsa |
| **10‑4** | Ricevuto / OK |
| **10‑7** | Fuori servizio / Pausa |
| **10‑8** | In servizio / Disponibile |
| **10‑12** | Presenza civile (o media presenti) |
| **10‑20** | Posizione attuale |
| **10‑23** | Arrivo a destinazione |
| **10‑27** | Controllo patente / registrazione veicolo |
| **10‑33** | Emergenza (priorità massima) |
| **10‑37** | Richiesta di conferma identità |
| **10‑42** | Trasporto a sede / custodia |
| **10‑99** | Richiesta immediata di supporto tattico |

### 1000.1.1 CODICI RADIO CLASSIFICATI (DOSP)
I codici dal **10‑100 al 10‑119** sono riservati esclusivamente agli scenari paranaturali. Ciascun numero identifica con precisione il tipo di fenomeno anomalo o la richiesta specialistica in modo che civili provvisti di scanner radio (o agenti non iniziati) non comprendano la reale entità del pericolo.

All’emissione di un **10‑33** (Emergenza) o un **10‑99** (Richiesta supporto), se la chiamata riguarda fenomeni paranaturali, l'agente A.A. deve specificare subito il codice esteso corrispondente (es. *"10‑33 e 10‑105 in corso"*).

| Codice | Significato |
| :--- | :--- |
| **10‑100** | Segnalazione fenomeno paranaturale non ancora classificato |
| **10‑101** | Attività LOP.LEY rilevata (Ley line attiva / Nodo) |
| **10‑102** | Attività LOP.CF rilevata (Confine aperto / Varco RE-ALT) |
| **10‑103** | Presenza LOP.R-EVS rilevata (Residuo energetico EVS) |
| **10‑104** | Presenza LOP.ART rilevata (Sito Artificiale / OOP‑indotto) |
| **10‑105** | Scissione di confine (EVS.SC) dimensionale in corso (Scissione di confine EVS.SC) |
| **10‑106** | Fenomeni psichici di massa in corso (EVS.PM) |
| **10‑107** | Ritrovamento OOP.N (Oggetto di Potere Nativo) |
| **10‑108** | Ritrovamento OOP.AL (Oggetto di Potere Alterato) |
| **10‑109** | Ritrovamento OOP.AR (Oggetto di Potere Artificiale) |
| **10‑110** | **BLACKOUT** / Breach critico o isolamento totale immediato |
| **10‑111** | Breach di contenimento OOP / OOP fuori controllo |
| **10‑112** | Richiesta intervento SRT / FEU per neutralizzazione |
| **10‑113** | Allarme contaminazione paranaturale (radiazioni/tossicologia esoterica) |
| **10‑114** | Richiesta intervento Unità di Custodia (DCU) per contenimento PU |
| **10‑115** | Evacuazione immediata area coinvolta / Emergenza civile |
| **10‑116** | Fenomeno paranaturale stabilizzato e neutralizzato con successo |
